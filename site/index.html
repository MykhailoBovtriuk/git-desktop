    First launch

    Windows says "protected your PC"

    SmartScreen flags the installer because it isn't code-signed. Click More info, then Run anyway.

    macOS can't verify the app

    Right-click Git Desktop.app → Open → Open. Once is enough. Or run xattr -dr com.apple.quarantine "/Applications/Git Desktop.app".

    Linux AppImage won't start

    Mark it executable first: chmod +x git-desktop-*.AppImage. The .deb installs with sudo dpkg -i.
